# Profile assets

- `hero.svg`, `hero-mobile.svg`, `dreamscape-card.svg`, `thomasin-card.svg` and
  `footer.svg` are original vector artwork created for this profile. They contain
  no scripts, remote images or external font dependencies. The spacecraft drawing
  is decorative, not a representation of an approved 3D model.
- The Dreamscape and spacecraft 991 PNGs are the corresponding projects' concept
  references. Their presentation pages explicitly distinguish concept art from
  screenshots, final renders and released episodes.
- Technology and contact badges are downloaded SVGs from [Shields.io](https://shields.io/).
  Recognizable project logos are supplied through its Simple Icons integration;
  brands remain associated with their respective owners. Badges indicate tools
  used, not certification, partnership or endorsement.

All visual assets are served from this repository. The profile does not depend
on an external statistics service, visitor counter or runtime-generated banner.
The main README uses the smaller vector cards; full concept images load on the
individual project pages.
